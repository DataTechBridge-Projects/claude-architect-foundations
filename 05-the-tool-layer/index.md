# The Tool Layer

Covers tool design as API design for a model rather than a human caller: naming and structuring tools so they're selected reliably, designing error responses a reasoning model can recover from, MCP architecture and governance, and Claude Code's built-in tools as a worked example.

**Official docs:** [Tool use overview](https://platform.claude.com/docs/en/agents-and-tools/tool-use/overview) · [MCP connector](https://platform.claude.com/docs/en/agents-and-tools/mcp-connector)
