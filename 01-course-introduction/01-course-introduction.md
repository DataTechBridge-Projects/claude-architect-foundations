# Course Introduction
{: .no_toc }

*Video duration: 3:03*

Welcome. This course is a complete study path for the **Claude Certified Architect - Foundations (CCA-F)**, Anthropic's certification for people who design solutions built on Claude — not just prompt it, but architect systems around it: agents, tools, workflows, and the context those agents run on.

CCA-F is a solution-architecture certification, not a coding test. It assumes you can already write software; what it checks is whether you can make sound *design* decisions when Claude is a component in a larger system. That means knowing when to reach for a single agent versus an orchestrated multi-agent workflow, how to define tools so a model uses them reliably, when a rigid pipeline beats an autonomous loop, how prompt structure shapes behavior at scale, and how to manage context so a long-running agent doesn't degrade as it works. Get comfortable with those trade-offs and the exam questions stop feeling like trivia and start feeling like decisions you've already made on a real project.

This course is for architects, tech leads, and senior engineers who are putting Claude into production — building internal tools, customer-facing agents, or automation pipelines — and want the vocabulary and judgment to defend those designs to a team, not just get them working once. Familiarity with APIs and basic LLM concepts is assumed; deep prior experience with Claude specifically is not.

Here's how the course is organized. We start with **Fundamentals**, a grounding module covering LLM basics and the practical differences between the Claude API and Claude Code, so everyone starts from the same baseline. From there we cover the certification itself: its five official domains and a five-layer mnemonic — Agentic, Tool, Workflow, Prompt, and Context — that we'll use as the backbone of the entire course. Each of those five layers then gets its own full module, going deep on the concepts, common failure modes, and design patterns the exam expects you to recognize. After the five layers, an **Additional Topics** module rounds out anything that doesn't fit neatly into one layer, and the course closes with a **Practice Exam** module built to mirror the real test's format and difficulty.

Every module ends with a short quiz and, for the meatier ones, a role-play scenario to pressure-test your reasoning out loud. Let's get started.
