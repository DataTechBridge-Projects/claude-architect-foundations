# Module Intro
{: .no_toc }

*Video duration: 2:27*

The Fundamentals module gave you the vocabulary: what an LLM actually is, how Claude Code differs from the raw Claude API, and what separates a genuine agent from a clever script. This module shifts the lens from the technology to the test itself. Before you sink dozens of hours into studying agentic architecture, tool design, workflows, prompting, and context management in real depth, it pays to understand exactly how the CCA-F exam is organized, what it's actually measuring, and how to walk into it prepared.

The Claude Certified Architect - Foundations credential is built around five domains, and each one maps directly to a layer of how production Claude systems get designed: Agentic architecture (how the orchestration loop decides what happens next), Tool design (the interface between the model and the outside world), Workflow design (how deterministic process and autonomous judgment combine), Prompt design (how instructions, examples, and structure shape model behavior), and Context management (what information the model can actually see, trust, and act on at any given moment). Modules 4 through 8 of this course each go deep on one of these domains in turn. This module is your map of the territory before you start walking it.

Across the next several lectures you'll get a full breakdown of what each domain covers and what an architect is expected to know within it, a memorable mental model — the five-layer mnemonic — for keeping the domains straight under exam pressure, a realistic walkthrough of exam-day logistics and test-taking strategy, a pointer to Anthropic's official CCA-F page for the details only the certification body can authoritatively confirm, and ten synthesized takeaways that preview the highest-value principles from the entire course.

Treat this module as calibration, not trivia. By the end of it, you should be able to look at almost any exam question and immediately place it: which domain is this actually testing, and what does a good architect do here? **That instinct will matter more on exam day than any single fact you memorize.**
